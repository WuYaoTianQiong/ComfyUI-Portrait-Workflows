# 2026-11-03 ZIT V13 窄比例与高画质 A/B

## 背景

用户反馈 `MoodyZIT_V13_Visual_文生图_双程采样_快速预览_文字渲染.json` 在 9:16 / 9:21 下容易画面扭曲。最初怀疑是 atelier 的 preset 适配器把短边压小（9:16 → 592×1040、9:21 → 512×1200）。同 prompt / 同 seed A/B 后，结论分两层：

1. **大尺寸/高画质**：第二程输出长边 ≥ 2448 或总像素 ≥ ~2.75MP 时，底部出现货架/地面纹理的拼贴；1.5× 下连 2:3 都崩。
2. **原生 9:16 也不是 100% 稳**：720×1280 + 1.7× 第二程，3 个 seed 里 1 个仍崩；把第二程长边压到 2048（672×1200）后 3/3 正常。

## 环境

- ComfyUI 0.41.3，RTX 5070 12GB，torch 2.9.0+cu130
- 工作流：ZIT V13，第一程 17 步 CFG3 euler/simple，`LatentUpscaleBy` 1.7 bislerp，第二程 11 步 CFG1 dpmpp_2m_sde
- 提示词：A 组全身街拍（便利店门口），seed 20261105 / 20261106 / 20261107
- 同 prompt / seed / 模型，仅改 `EmptyLatentImage` 宽高

**结论修正：9:21 不是“所有模型都 OOD”。** 这三个单程工作流在 ~2.3–2.5MP 下直出 9 张全部正常，脚/鞋/地面没有拼贴。**ZIT 是特例**：它的 1.7× 第二程放大在 9:21 下更容易崩，不代表 9:21 本身不可做。

## 结论

1. **9:21 可以直出，但要选对工作流**：Qwen / Krea2 / Porn 都行（9/9）；ZIT 的 1.7× 第二程是特例。9:16 同理，ZIT 需要 2048 上限，其他单程工作流没有这个问题。
2. **原生 9:16 不保证**：720×1280 + 1.7× 是 2/3（样本小，但已足以否定“必定正常”）。
3. **2048 长边上限可稳住 9:16**：672×1200 → 1144×2040，3/3 正常；这是目前验证过的 Atelier 修法。
4. **大尺寸仍必崩**：1.5×（约 4MP）下 9:16 / 9:21 / 2:3 全部拼贴；9:21 把短边加到 640×1488 也更糟。
5. ZIT 的 9:21 1.0× 512×1200 只测了 1 个 seed；但 9:21 直出可改用 Qwen / Krea2 / Porn（第三轮 9/9），不必在 ZIT 上硬做。
6. 第一程直出测试无效：第一程 `return_with_leftover_noise=enable`，直接解码是噪声，必须由第二程收尾。

## 对“ComfyUI 直接跑”的结论

- **原工作流 9:16 不保证正常**：原生 720×1280 + 1.7× 在 3 seed 里 1 个崩。
- 要让 ComfyUI 直接跑也稳，三选一：
  1. 手动把第一程设成 **672×1200**（工作流 picker 没有这个档，需要断开 picker 连线手动填），保持 1.7×，最终 1144×2040；3/3 正常。
  2. 把 `LatentUpscaleBy` 改成 **1.0**，输出 720×1280，之后接 SeedVR2；3/3 正常。
  3. 做一份**副本工作流**，加“第二程长边 ≤2048”的钳制节点；原版不动。
- 只改 Atelier 的话，原工作流在 ComfyUI 里仍是原样，不会自动获得这个上限。
- **9:21 不需要改 ZIT**：直接用 Qwen 2.1 / Krea2 V8SE / PornMaster V25 直出（第三轮 9/9 正常）。

## Atelier 修法（2026-11-04 已落地）

- **比例按节点真实选项检测**：`ResolutionPresetPicker` / `ResolutionSelector` 从 object_info 读；ZIT 前端只保留 7 个真实比例，**9:21 不显示**；绕过前端调 API 也会被 400 拒绝。
- **2048 长边上限**：解析 `LatentUpscaleBy.scale_by`（ZIT=1.7），把第一程压到「第二程长边 ≤ 2048」。实测 9:16 1.5×：880×1568 → 672×1200，成品 1144×2040。
- **单程工作流**（Qwen/Krea2/Porn，post_scale=1）继续开放 9:21 的字面量扩展。
- 前端画质标签同步按 2048 上限计算，不再显示未钳制的成品尺寸。
- 遗留：文件名前缀仍未同步 picker preset，9:16 输出仍叫 `…_2×3_…`。
