## 结论

- **图内中文文字优先 Qwen2.1**；ZIT 次选；Porn / Krea2 / Flux 不用于文字。
- Krea2 能写四个大字，但写不对店招小字；Flux2 能理解中文提示词，但图内汉字不可用。
- 纯人像依从性 PornMaster 最好；Qwen 最自然但容易看镜头；ZIT/Krea2 偏偶像感；Flux 光偏平。
- 提示词长度：本轮把原 1800–2000 字压到 700–900 字、去掉冲突氛围词后，依从性明显更好。

## 负向验证（2026-11-03 晚，编译器接入后）

同一 C 组提示词、同 seed、同尺寸，新增 6 张：

- `output/NEG_TEST_20261103/`：ZIT 编译负向 ×2、Qwen 编译 CFG1 ×2、Qwen 编译 CFG2 ×2；
- 对照总表：`negative_compare_20261103.jpg`（本目录）。

| 方案 | seed 20261103 | seed 20261104 | 耗时 |
|---|---|---|---|
| ZIT 基准（无编译） | 卷轴有落款+印章 | 卷轴有落款+印章 | — |
| ZIT + 编译负向 | 卷轴签名消失，但桌面宣纸出现大量小字 | 落款+印章仍在，桌面小字更多 | 40–43s |
| Qwen 基准（CFG1，无编译） | 卷轴干净 | 卷轴干净，桌面宣纸有小字 | — |
| Qwen 编译 CFG1 | 卷轴干净，桌面少量小字 | **卷轴出现落款+印章** | 38s |
| Qwen 编译 CFG2 | 卷轴干净、桌面空白 | 卷轴干净、桌面空白 | **65s（约 1.7×）** |

结论：

- **Qwen + 编译器 + CFG=2 是唯一 2/2 都干净（无落款/印章、桌面无杂字）的方案**，代价约 1.7 倍耗时；
- Qwen CFG=1 即使做了正向改写，负向仍不生效，seed04 会重新长出落款印章；
- ZIT 负向确实能影响卷轴签名，但跨 seed 不稳定，且压不住桌面小字，不能作为“绝对无字”的保证；
- 仍建议保留后期清理链路（OCR/擦除/重排），负向只作为概率性改善。

## 负向条件实况（本轮之前）

查执行 API 图：

- Qwen：`negative_prompt` 字段存在，但 cfg=1，采样时无效；
- Krea2 / Porn / Flux：负向是 `ConditioningZeroOut`，没有负向通道；
- 只有 ZIT 第一程 cfg=3 真实接入负向。

因此“不要看镜头 / 不要落款印章 / 不要其他文字”在这四条线上压不住，C 组仍加印章；负向只能靠 CFG 减法，正向里写“不要”不可靠。

后续实现：Atelier 已加负向能力探测（`negative_effective`）与单框提示词编译器；见 `../文档/重构审计/待办总表_20261103.md`。
