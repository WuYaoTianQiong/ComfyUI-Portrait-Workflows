# 我的工作流（用户自建）

把自己的 ComfyUI 工作流（**API 格式** `.api.json`，或界面里"导出(API)"得到的 JSON）
丢进本目录，刷新「AI 参考图库 → 合成台」页面即可在下拉框里看到，标为 **我的工作流**。

## 会被列出的条件

后端 `/api/workflows?scope=studio` 对每个候选文件做结构判定，**必须同时满足**：

1. 至少一个 `LoadImage*` 节点（放参考图，1 个也行，2 图/4 图工作流同样可用）；
2. 至少一个文本编码节点（`CLIPTextEncode` / `TextEncodeQwenImageEditPlus` / `TextEncodeQwenImageEdit` 等）
   且带 `text` 或 `prompt` 输入；
3. 不是视频工作流（不含 `SaveVideo` / `VideoCombine`）。

不满足的（纯文生图、纯超分、图生提示词）不会出现在合成台下拉里，避免选中后才报错。
下拉里每项后面会标槽位数，例如「（3 图）」，与「人像 + 服装 + 姿势」对不上时会黄字提示。

## 命名建议

`<用途或模型>_<槽位>图_<步数>_<特点>.api.json`，例如
`我的_Flux换装_2图_8步_试稿.api.json`。
文件名会原样出现在下拉里，取个能一眼看懂的名字即可（前缀 `图库专用_` 留给官方那批）。

## 不想放文件？

合成台「工作流」一栏还有 **导入 .json**：选任意位置的 JSON 即可临时使用（标为「自定义工作流」），
它只存在浏览器本地配置里，不进本目录、也不会出现在其他人/其他浏览器的下拉中。
