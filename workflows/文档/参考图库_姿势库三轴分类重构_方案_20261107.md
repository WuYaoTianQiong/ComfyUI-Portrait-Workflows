## 1. 现状问题（2026-11-07 截图实测）

当前「体系」胶囊混了四个维度：构图、人数、分级、内容；PSL 只贡献了「来源 + 分级」。

| 胶囊 | 构图 | 人数 | 分级 | 内容 |
|---|---|---|---|---|
| 全身单人・标准系 | 全身 | 单人 | 全年龄 | 姿势类型 |
| 上半身单人 | 上半身 | 单人 | 全年龄 | 风格（可爱/挤胸/性感） |
| 全身单人・性感系 | 全身 | 单人 | 18+ | 姿势类型 |
| 双人缠绵 | 双人 | 双人 | 18+ | 体位 |
| pose-studio-lite・正常姿势 | 混合 | 混合 | 全年龄 | 混合 |
| pose-studio-lite・成人风格 | 混合 | 混合 | 18+ | 混合 |

另外两个硬问题：

1. **计数口径不同**：上游胶囊数字是「图片数」（73 姿势 × 5 视角 = 365），PSL 是「姿势数」（107 × 1）。按姿势组数，PSL 正常并不小。
2. **分类下拉混轴**：上游「上半身单人」的分类是风格，「全身单人」的分类是姿势类型，「双人缠绵」的分类是体位；PSL 又把类型/风格/体位混进同一个 `facet`。

## 2. 目标模型

### 2.1 五个字段，三个筛选轴

| 字段 | 取值 | UI |
|---|---|---|
| `source` | `upstream` / `pose-studio-lite` | 来源下拉 |
| `nsfw`（复用） | `true/false` | 分级下拉：全部 / 全年龄 / 18+ |
| `composition` | `full` / `upper` / `pair` / `unknown` | 一级胶囊：全部 / 全身单人 / 上半身单人 / 双人 |
| `pose_type` | 站/坐/跪/躺卧/蹲/前倾/后仰/扭转/特殊/未分类；双人用体位 | 姿势类型下拉（随构图收窄） |
| `style` | 标准/性感/可爱/胸线强调/特殊/未分类 | 风格下拉 |

- 原有 `group` / `facet` 保留，用于卡片副标题、搜索和兼容旧调用；筛选不再依赖它们。
- `nsfw` 仍是唯一分级真源；不再把「性感系/双人缠绵」当体系名。
- 安全模式打开时：分级固定「全年龄」，18+ 选项禁用；解锁逻辑不变。

### 2.2 计数口径

一律用**姿势组数**，不用图片数：

- 上游同一个 `体系|姿势编号` 的 5 个角度算 1 组；
- PSL 每条 1 个角度，算 1 组；
- 「全部」显示 `568 组`，悬停 title 补 `1,719 张`；
- 一级胶囊显示各组组数；来源/分级筛选变化时重新计数，姿势类型/风格/角度/搜索不改变一级胶囊计数（与现有交互一致）。

真实分布：

| 构图 | 上游 | PSL | 合计 |
|---|---:|---:|---:|
| 全身单人 | 153 | 151 | 304 |
| 上半身单人 | 80 | 80 | 160 |
| 双人 | 55 | 49 | 104 |
| 合计 | 288 | 280 | 568 |

安全模式（全年龄）下：全身 147 / 上半身 107 / 双人 6 / 合计 260。

## 4. UI 调整

### 4.1 一级胶囊（替换现有体系胶囊）

- 全部（568）
- 全身单人（304）
- 上半身单人（160）
- 双人（104）

### 4.2 第二排筛选

| 控件 | 选项 |
|---|---|
| 搜索 | 姿势名/编号/分类/ID（补充 canonical 字段） |
| 来源 | 全部来源 / 原图库 / pose-studio-lite |
| 分级 | 全部分级 / 全年龄 / 18+（安全模式下固定全年龄并禁用） |
| 姿势类型 | 全部类型 + 当前构图下的 canonical 类型 |
| 风格 | 全部风格 + canonical 风格 |
| 视角 | 现有视角胶囊 |
| 重置 | 重置全部 |

姿势类型选项随构图收窄：

- 全身：站立/坐姿/跪姿/躺卧/蹲姿/前倾/后仰/扭转/特殊/未分类
- 上半身：上半身/未分类（风格下拉承担细分）

- 全部：只显示单人/上半身类型；双人体位需先选「双人」，避免下拉混入 20+ 个体位

### 4.3 卡片

- `meta-left`：保留原体系（PSL 卡片会显示 `pose-studio-lite・…`，来源仍可见）；
- `meta-right`：显示 `pose_type · style`；

## 8. 风险与回滚

| 风险 | 处理 |
|---|---|
| 映射误判（尤其 PSL `sexy`、双人体位） | 映射写成显式表并加测试；保留原 `group/facet` 供核对 |
| 计数从图片变组数，用户觉得数字变小 | 胶囊 title 标注「组 / 图片」；文档说明 |
| 旧持久化 PoseItem 缺新字段 | 前端缺省 `unknown`/`''`，不崩；旧数据仍可按原体系显示 |
| 安全模式与分级筛选冲突 | 安全模式强制 general；18+ 选项禁用；解锁后恢复可选 |
| 分类重构影响配方 | 配方只提交 `pose_id`，与筛选无关；验收覆盖 PSL 出图 |

回滚：保留原 `group/facet` 与现有 `buildPoseGroups`；如新筛选有问题，前端可临时只渲染旧体系胶囊，后端字段不影响旧接口。

- PSL 双人体位到上游体位的归一（如「坐在上方→骑乘位」「前后位置→后入位」「正对卧位→正常位（传教士）」）是按语义近似，原始 `facet` 仍保留，可在卡片搜索/数据里追溯。

- PSL 与上游仍有约 25 个同名姿势（约 9%），分类重构不做去重。
