## 2. 路线 A（推荐）：Qwen-Image 2.1 + Fun ControlNet Union + OpenPose

### 2.1 本机已有资产（全部实测存在）

| 资产 | 路径/值 |
|---|---|
| 基线工作流 | `workflows/历史工作流/Qwen21_NSFW_文生图_25步_int8_OpenPose控姿_12G.json` |
| 主模型 | `diffusion_models/qwen_image_2.1_int8_convrot.safetensors` |
| 文本编码器 | `text_encoders/qwen3vl_8b_fp8_scaled.safetensors`（type=`qwen_image`） |
| VAE | `vae/qwen_image_2.1_vae_bf16.safetensors` |
| ControlNet | `model_patches/qwen_image_2.1_fun_controlnet_union_int8_convrot.safetensors` |
| 接线 | `LoadImage/预处理 → QwenImageDiffsynthControlnet(model, model_patch, vae, image, strength) → KSampler.model` |

工作流内置说明原文（实测记录）：

> 控制路径：`ModelPatchLoader`(fun_controlnet_union_int8) → `QwenImageDiffsynthControlnet`(strength 1.0)
> 骨架来源：`Nui.OpenPoseEditor` 手动摆姿，输出 `dw_pose_image` 直接接控制图
> **实测**（0.41.3 + 2.1 int8）：Canny 控制图 → 姿态/构图跟随、场景与服装按提示词替换，**30s/张**
> 想更贴骨架：strength 提到 1.2~1.5；想放开发挥：0.6~0.8

### 2.2 改造点（已实测的那版接线）

```json
"1": LoadImage(姿势库 img/depth/pair60_P002_low.webp)
"2": UNETLoader(qwen_image_2.1_int8_convrot.safetensors)
"3": CLIPLoader(qwen3vl_8b_fp8_scaled.safetensors, type=qwen_image)
"4": VAELoader(qwen_image_2.1_vae_bf16.safetensors)
"5": TextEncodeQwenImage21(clip, prompt, negative_prompt, resolution=1024)   → positive/negative
"7": ModelPatchLoader(qwen_image_2.1_fun_controlnet_union_int8_convrot.safetensors)
"8": QwenImageDiffsynthControlnet(model=2, model_patch=7, vae=4, image=1, strength=1.3)
"6": EmptyLatentImage(1024×1024)
"9": KSampler(model=8, positive=5.0, negative=5.1, latent=6, steps=25, cfg=1.0)
```

1. **控制图用深度图**，不要用白模原图再去跑预处理器：`img/depth/*.webp` 全库 1439 张已现成，文件名与原图一一对应（`img/full_sexy_P001_front.png` → `img/depth/full_sexy_P001_front.webp`），前端 `poseImagePath()` 已在做这个映射。
2. **双人不需要特殊处理**：深度图里两个人的形体都在，ControlNet 按像素关系生成两个人，实测成立。
3. `strength` 实测 1.3 可用；再高会更贴控制图但画面变僵硬，建议 1.0–1.3 区间调。
4. **画布用 `EmptyLatentImage` 固定**（1024×1024 或按成品规格），**不再由姿势图裁切比例决定** —— 这条同时修掉"双人图变方图 → 单人特写"。
5. 25 步、cfg 1.0 是 2.1 的正确用法（不是蒸馏 4 步），不要照搬 Edit 的参数。

### 2.3 遗留问题（待验证）

- **人脸一致性**：2.1 文生图没有 `ReferenceLatent`，人像参考只能靠文字描述 → 需要第二段 Edit 换脸。
- **服装一致性**：同样只能靠文字，实测结果里服装是"同色系"而不是"逐件还原"。需要第二段 Edit。
- **白模原图直接作控制图**（不走深度）是否同样有效：未测。

## 4. 推荐落地形态：两段式流水线

```
姿势库白模 → OpenposePreprocessor ─┐
                                   ├→ Qwen-Image 2.1 + Fun ControlNet  →  姿势正确的真人底图（30s）
人像/服装提示词 ───────────────────┘
                                              ↓
                               Qwen-Image-Edit 2511 三图（人像+服装+底图）
                               → 换脸 / 换装，姿势由底图决定
```

理由：路线 A 解决"姿势"，路线 C 解决"人脸与服装"，两者各做擅长的事，避免用一个模型同时背四个约束。

第 2 段具体接法（待验证）：把 A 的产出图接到 `LoadImage` 并替换原 `image3`（姿势槽），同时保留 `image1` 人像、`image2` 服装；`#10 ImageScaleToTotalPixels` 改为接该图，让画布也跟随它。

### 9.4 下一步（只剩两条，都需要新组件）

1. **双人专用 LoRA**：VNCCS 系与 Qwen Edit 系都是单角色训练。需要找"双人互动"训练的 LoRA 或模型，否则 prompt 层面无法稳定突破。
2. **组合式产出**：分两次生成单人真人（已验证 52s），再用外部合成/局部重绘（`editor` 的局部重绘链路）拼成双人。这条路不依赖模型理解"两个人"，但工程量大。

在拿到上述任一方案前，**不建议在 UI 上宣称"双人姿势可控"**；最多提示"双人姿势不保证，请多抽几次"。
