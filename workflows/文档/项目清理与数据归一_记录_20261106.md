### 第 1 步：停服

```powershell
Stop-ScheduledTask -TaskName "AtelierTempLaunch" -ErrorAction SilentlyContinue
# 变量名不要用 $pid（PowerShell 只读自动变量）
$conn = Get-NetTCPConnection -LocalPort 8656 -State Listen -ErrorAction SilentlyContinue
if ($conn) {
    $backendPid = ($conn | Select-Object -First 1).OwningProcess
    Get-CimInstance Win32_Process -Filter "ProcessId=$backendPid" | Select-Object CommandLine
    # 确认 CommandLine 含 main.py 后再杀；勿误杀 8188（ComfyUI）
    Stop-Process -Id $backendPid -Force
}
```

### 第 2 步：先 checkpoint 再回移（顺序不可交换）

> `data/prompts.db-wal` 里可能有已提交未回写的记录。强杀进程后 SQLite 不会自动 checkpoint，直接搬主库会丢数据（实测曾差 2 条）。

```powershell
$W = "F:\ComfyUI_Migration\ComfyUI-Portrait-Workflows\workflows"
$D = "$W\脚本\atelier\data"

& "C:\Users\ws\AppData\Local\Python\pythoncore-3.12-64\python.exe" -c "import sqlite3; c=sqlite3.connect(r'$D\prompts.db'); print('ckpt=', c.execute('PRAGMA wal_checkpoint(TRUNCATE)').fetchone()); print('rows=', c.execute('select count(*) from gen_history').fetchone()); c.close()"
# 期望 ckpt=(0,0,0) 或前两项为 0；非 0 说明还有连接占用，停干净再试

New-Item -ItemType Directory -Force "$W\thumbnails", "$W\uploads", "$W\文档\backups" | Out-Null
Copy-Item "$D\prompts.db" "$W\文档\提示词收藏.db" -Force
Move-Item "$D\thumbnails\*" "$W\thumbnails\"   -Force
Move-Item "$D\uploads\*"    "$W\uploads\"      -Force
Move-Item "$D\backups\*"    "$W\文档\backups\" -Force
```

不要删除 `data/` 下的 `-wal` / `-shm`：checkpoint 后 `-wal` 为 0 字节，随连接关闭由 SQLite 回收。
